# Pre-Registration PR-2026-01 — T1-R: BCI-IV-2b Reproduction

**Status:** Draft — pending sign-off from both team members

**Experiment:** T1-R (Track A Reproduction Baseline)
**Date opened:** 2026-08-07

## 1. Hypothesis

Using a CSP + shrinkage-LDA (sLDA) pipeline on BCI Competition IV Dataset 2b
(left-hand vs. right-hand motor imagery, 9 subjects), under an honest
session-wise train/test split, we expect to reproduce per-subject accuracy
in the same range as the CSP+SVM baseline reported in Wang et al. (2023),
mean 64.7% ± 6.4% SD across subjects.

Tolerance: we consider the reproduction successful if our mean accuracy
falls within the published mean ± 2 SD (i.e., roughly 52%–78%), given the
classifier deviation noted below.

## 3. Planned deviation — stated up front

The manual's T1-R protocol specifies a **CSP + sLDA** classifier. The
source paper does not report a CSP+sLDA number — its simplest baseline
is **CSP+SVM** (64.7% ± 6.4%). We are treating this as the closest
available reference point rather than a true apples-to-apples target.

Consequence: any accuracy delta we observe may be partly attributable to
the SVM→sLDA classifier swap, not solely to our pipeline or evaluation
honesty. We will not interpret a below-baseline result as evidence of a
pipeline bug on this basis alone — see Failure Modes below.

## 4. Pipeline (per Track A manual §5.1)

1. Load BCI-IV-2b via `data/bci_iv_2b.py`, record version hash.
2. Band-pass 8–30 Hz (`preprocessing/eeg_filters.py`).
3. Epoch 0.5–3.5 s post-cue (`preprocessing/epoching.py`), matching the
   source paper's window.
4. CSP feature extraction (`eeg/decoders_linear.py`).
5. sLDA classifier (per manual protocol, not the source paper's SVM).
6. Block-wise split via `eval/splits.py` — session-wise (2b provides
   multiple recording sessions per subject).
7. Label-shuffle surrogate via `eval/surrogates.py`.
8. Per-subject accuracy with bootstrap CIs via `eval/stats.py`
   (≥1000 resamples).

## 5. Controls (mandatory per manual)

- **Block-wise (session-wise) split** — verified before any result is
  reported, not assumed.
- **Label-shuffle surrogate** — run alongside the real result, reported
  in `surrogates.md`.

## 6. What a wrong result looks like

- **Far above 64.7%** (e.g., >85% mean) → suspect leakage first. Check
  the split is genuinely session-wise and not window- or trial-level
  before attributing this to a good pipeline.
- **Far below the tolerance band** (e.g., <45%, near chance) → check
  epoch timing and band definition before concluding the pipeline is
  broken. Also check channel selection (only C3/Cz/C4, EOG excluded).
- **Within tolerance** → treat as a successful reproduction given the
  stated classifier deviation; report the exact delta and offer a
  one-line hypothesis for its direction (e.g., "sLDA underperforms SVM
  slightly on this feature set, consistent with X").
