## 1. Hypothesis

Using a CSP + shrinkage-LDA (sLDA) pipeline on BCI Competition IV Dataset
2a (left-hand vs. right-hand motor imagery subset, 9 subjects), under an
honest session-wise (train on session T, test on session E) split, we
expect to reproduce per-subject accuracy in the same range as the
CSP+SVM baseline reported in Wang et al. (2023), mean 66.8% ± 9.1% SD
across subjects.

Tolerance: we consider the reproduction successful if our mean accuracy
falls within the published mean ± 2 SD (i.e., roughly 48.6%–85.0%),
given the classifier deviation noted below.

## 3. Planned deviations — stated up front

**Deviation 1 — dataset switch (2b → 2a).** T1-R was originally
pre-registered on BCI-IV-2b (3 EEG channels: C3, Cz, C4). Before any
result was obtained on 2b, we switched to BCI-IV-2a (22 EEG channels)
because 3-channel CSP showed poor visual class separation at the
required pre-modeling checkpoint (§5.1 stop-and-debug gate), and 22
channels gives CSP meaningfully more spatial information to work with.
Wang et al. (2023) reports a directly comparable CSP+SVM baseline for
2a as well as 2b, so the same source paper and same deviation-2
(classifier swap) logic carries over unchanged — only the dataset and
its published target number change.

**Deviation 2 — classifier (SVM → sLDA).** The manual's T1-R protocol
specifies a CSP + sLDA classifier. The source paper does not report a
CSP+sLDA number for either dataset — its simplest baseline is CSP+SVM
(66.8% ± 9.1% on 2a). We are treating this as the closest available
reference point rather than a true apples-to-apples target.

**Deviation 3 — class subset.** BCI-IV-2a is natively 4-class (left
hand, right hand, foot, tongue). Per the manual's 2-class requirement,
we use only the left-hand and right-hand trials (72 per class per
session, ~144 per session after filtering), discarding foot/tongue
trials entirely. This roughly halves the usable trial count per subject
compared to the native 4-class dataset.

Consequence of all three: any accuracy delta we observe may be
attributable to the classifier swap, the class-subset reduction, or our
pipeline/evaluation choices — not necessarily leakage or a bug. We will
not interpret a below-baseline result as evidence of a pipeline bug on
this basis alone, nor an above-baseline result as automatic success
without first checking for leakage (see §6).

## 4. Pipeline (per Track A manual §5.1)

1. Load BCI-IV-2a via `data/bci_iv_2a.py`, filtered to left/right-hand
   trials only; record version hash (`compute_dataset_hash`).
2. Band-pass 8–30 Hz (`preprocessing/eeg_filters.py`).
3. Epoch 0.5–3.5 s post-cue (`preprocessing/epoching.py`), matching the
   source paper's window.
4. CSP feature extraction (`eeg/decoders_linear.py`).
5. sLDA classifier (per manual protocol, not the source paper's SVM).
6. Session-wise split via `eval/splits.py` — train on session T, test
   on session E (2a's native train/test structure, cleaner than
   inventing a session grouping as 2b would have required).
7. Label-shuffle surrogate via `eval/surrogates.py`.
8. Per-subject accuracy with bootstrap CIs via `eval/stats.py`
   (≥1000 resamples).

## 5. Controls (mandatory per manual)

- **Session-wise split (train=T, test=E)** — verified before any result
  is reported, not assumed. This is a between-session split by
  construction (T and E were recorded as genuinely separate sessions),
  so it satisfies the block-wise requirement without needing an
  additional grouping decision.
- **Label-shuffle surrogate** — run alongside the real result, reported
  in `surrogates.md`.

## 6. What a wrong result looks like

- **Far above 66.8%** (e.g., >85% mean) → suspect leakage first. Check
  that training genuinely only touches session T and testing only
  touches session E, with no trial or window crossing between them,
  before attributing this to a good pipeline or to the 22-channel
  advantage alone.
- **Far below the tolerance band** (e.g., <45%, near chance) → check
  epoch timing and band definition before concluding the pipeline is
  broken. Also check channel selection (22 EEG channels, prefix
  `EEG-`, EOG excluded) and the left/right class filter (values 1/2 out
  of the native 1–4 labels).
- **Within tolerance** → treat as a successful reproduction given the
  stated deviations; report the exact delta and offer a one-line
  hypothesis for its direction.
- **Individual subjects near-ceiling (e.g. >95%)** → not automatically
  suspicious in isolation. Subject A08 in particular is documented in
  independent literature as an easy subject across multiple unrelated
  methods (CSP-based and LDA-based alike) reaching 90–99% accuracy — a
  single high-performing subject is not on its own evidence of leakage.
  Uniform near-ceiling performance *across all subjects* would be a
  different, more concerning pattern and should still prompt a leakage
  check.
